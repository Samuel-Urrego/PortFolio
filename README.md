A high-performance, responsive portfolio built with **Astro 4.0**, **Tailwind CSS**, and **TypeScript**. Designed for Backend Architects and AI Orchestrators who value system logic, information density, and terminal-grade aesthetics.

> "Architect of the invisible. I design the logic that holds the digital world together while others only see the surface."

## Quick Path

1. **Install**: `npm install`
2. **Launch**: `npm run dev`
3. **Build**: `npm run build`

## Logic Stack

| Layer | Technology |
|-------|------------|
| **Core** | [Astro](https://astro.build/) (v4.0) |
| **Logic** | [TypeScript](https://www.typescriptlang.org/) |
| **Styling** | [Tailwind CSS](https://tailwindcss.com/) |
| **Routing** | Native i18n (EN/ES) |
| **Visuals** | Custom Canvas (Matrix Rain) & JS Scramble FX |

## System Features

- [x] **Multi-Language Support**: Native i18n routing (`/` for English, `/es/` for Spanish).
- [x] **Responsive Terminal UI**: Fully optimized for mobile with custom overlay navigation.
- [x] **Atomic Architecture**: Modular component structure for high scalability.
- [x] **Cyber Aesthetics**: Matrix rain backgrounds, noise overlays, and CRT effects.
- [x] **Performance First**: Zero JS by default, hydrated only where logic is required.

## Architecture: Atomic Logic

The project follows a modified **Atomic Design** pattern to ensure modularity and separation of concerns:

- `src/components/`: Reusable logic units (Button, Modal, Card).
- `src/layouts/`: Global system wrappers (Matrix Rain, CRT effects).
- `src/i18n/`: Centralized translation dictionaries and routing utilities.
- `src/pages/`: Locale-specific entry points.

## Deployment

Designed to be deployed on **Vercel** or **Netlify** with zero configuration.

```bash
# Verify system integrity
npm run check
```
